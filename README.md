# 自動パッチノート メタ回転バトル

2vs2のバトルを繰り返すたびに、勝敗結果に応じてキャラクターが自動でナーフ・アッパーされ、
パッチノートが際限なく積み重なっていくスマホ向けバトルゲームです。

## 遊び方

```bash
npm install
npm run dev
```

ブラウザで表示されたURL（スマホの縦画面サイズを推奨）にアクセスしてください。

- **バトルへ**: PvP（一人で両チーム操作）/ PvE（Bチームの2キャラをNPCが操作）を選び、
  バン・ピック（先攻BAN→後攻BAN→先攻PICK×1→後攻PICK×2→先攻PICK×1）を経てバトル開始。
- 15×15マスのフィールド上で、行動ターンごとに「移動」と「スキル／クイックスキル」を使用できます。
  - 移動は画面右下のスティックをドラッグして操作します（マス単位で移動ポイントを消費）。
  - スキル・クイックスキルは、対象選択が必要なものはグリッド上のキャラをタップ、
    範囲攻撃やバフなど対象選択が不要なものはボタンを2回タップして発動します。
- **パッチノートを確認**: これまでの全パッチノート（最新・過去分すべて）を閲覧できます。
- **キャラ現在ステータス確認**: 現在の全キャラのステータスを文章で確認できます。ℹ️ボタンで初期値も確認可能。
  オレンジ色の数値はナーフ・アッパーの対象になりうるステータスです。
- **初期化**: パッチノートを全て消去し、全キャラを初期ステータスに戻します。

## 試合後のナーフ・アッパー処理

1. 勝ったチームのキャラ1体はランダムに**大ナーフ**、残りは**中ナーフ**。
2. 負けたチームのキャラはランダム1体のみ**中アッパー**。
3. バン・ピックされたキャラからランダム1体は**小ナーフ**、別のランダム1体は**小アッパー**。
4. 上記で変更されていないキャラから、ランダム2体が**小アッパー**、またはランダム1体が**大アッパー**。

処理後、変更内容はランダムな順番でパッチノートとして記録されます。この試合サイクルを繰り返すことで、
メタが際限なく回転し続けます。

## 技術構成

- React + TypeScript + Vite
- 状態管理: Zustand（`localStorage` にキャラの現在ステータスとパッチノート履歴を永続化）
- ルーティング: react-router-dom（HashRouter）
