# ラスト・バスティオン / CORE DEFENSE 3D

四方のゲートから押し寄せる大量の敵から、中央の**エナジーコア**を守り抜く
**一人称タワーディフェンスシューター**です。自分の銃で前線に立ちながら、
撃破報酬でタワーを建設・強化し、20 ウェーブの侵攻を凌ぎます。

WebGL（three.js）+ React + TypeScript で実装しており、外部の 3D モデルや
音源ファイルは一切使用していません。地形・敵・武器のモデル、テクスチャ、
効果音・BGM はすべて実行時にプロシージャル生成しています。

## 遊び方

```bash
npm install
npm run dev
```

表示された URL をブラウザで開き、難易度とグラフィック品質を選んで「出撃する」。
画面をクリックするとマウスがロックされ、一人称視点で操作できます。

### 基本の流れ

1. **防衛準備フェーズ**（初回 25 秒／以降 13 秒）に <kbd>Tab</kbd> で俯瞰の建設モードへ。
   タワーを配置します。<kbd>Enter</kbd> で即時開始すると残り時間に応じたボーナス資金が入ります。
2. **ウェーブ**が始まると、4 つのゲートから敵が侵攻経路（赤い矢印の道）に沿ってコアへ向かいます。
3. タワーの弾幕と自分の射撃で敵を殲滅します。撃破報酬（クレジット）で増設・強化。
4. コアの耐久が 0 になると敗北。20 ウェーブを凌ぎ切れば勝利です。

### 操作

| 操作 | キー |
| --- | --- |
| 移動 | `W` `A` `S` `D` |
| ダッシュ | `Shift` |
| ジャンプ | `Space` |
| 射撃 | 左クリック |
| エイム（ADS） | 右クリック |
| リロード | `R` |
| 武器切替 | `1` `2` `3` / ホイール |
| 建設モード切替 | `Tab` または `B` |
| タワー種別選択（建設中） | `1` – `4` |
| 強化 / 売却（建設中） | `U` / `X` |

| ミュート | `M` |
| ポーズ | `Esc` |

建設モードではマウスでマスを選び左クリックで設置、設置済みタワーをクリックすると
性能と強化・売却の操作パネルが開きます。

## ゲーム内容

### 武器（3 種）

| 武器 | 特徴 |
| --- | --- |
| VK-7 アサルトライフル | フルオート。汎用。弱点（上部）ヒットで 1.7 倍 |
| MB-12 ブリーチャー | 散弾 10 発。近距離で圧倒的だが射程が短い |
| ARC-9 レールガン | 貫通 6 体＋着弾点に小爆発。単発高火力 |

### タワー（4 種 × 3 レベル）

| タワー | コスト | 役割 |
| --- | --- | --- |
| ガトリング砲 | 80 | 高速連射の基本タワー。対空可 |
| キャノン砲 | 145 | 着弾点に範囲ダメージ。密集した地上敵に有効 |
| フロストビーム | 115 | 照射した敵を継続的に減速。足止め役 |
| テスラコイル | 210 | 雷撃が敵から敵へ連鎖。群れの処理に最適 |

### 敵（6 種）

グラント（標準）／ランナー（高速）／フライヤー（飛行・経路無視で直進）／
スティンガー（遠距離射撃。プレイヤーとタワーを狙う）／ブルート（重装甲）／
タイタン（5 ウェーブごとのボス。遠距離砲撃つき）。

飛行する敵は経路を無視して直線でコアへ向かうため、対空可能なタワー
（ガトリング・フロスト・テスラ）が必要です。

## 技術構成

- **React + TypeScript + Vite** — UI/HUD と画面遷移
- **three.js** — レンダリング。ACES トーンマッピング、シャドウマップ、UnrealBloom
- **Zustand** — ゲームループ（命令的）と React HUD（宣言的）の橋渡し。
  数値は約 12Hz に間引いて反映し、ヒットマーカーやダメージ表示など即応性が要る
  演出はゲーム側が直接 DOM を操作
- **WebAudio** — 効果音と環境音をすべて合成。戦況に応じて BGM の緊張感が変化
- **プロシージャル生成** — マップ（4 レーンが中央のリング路に合流）、地形テクスチャ、
  敵・タワー・武器のモデル、空のシェーダー

### パフォーマンス上の工夫

- 粒子・弾丸・HP バー・トレーサーはすべて `InstancedMesh` で 1 ドローコールに集約
- 敵モデルは種別ごとにジオメトリをマージし、本体＋発光部の 2 マテリアルに統合
- 敵は種別ごとにプールして再利用（`spawn` / `recycle`）
- 近傍探索は XZ 平面の空間ハッシュ（分離挙動・タワーの索敵・雷撃の連鎖）
- 被弾判定はカプセルとレイの解析解、地形はグリッド DDA で走査
- グラフィック品質（LOW / MEDIUM / HIGH）で影・ブルーム・解像度スケールを切替。
  ポーズ画面からいつでも変更可能

## ディレクトリ構成

```
src/
  game/
    config.ts          バランス定義（敵・タワー・武器・ウェーブ生成）
    Game.ts            全体の統括（ウェーブ進行・経済・カメラ・入力）
    state.ts           React へ渡す UI ステート（Zustand）
    core/              Engine / Input / Audio / 汎用ユーティリティ
    world/             マップ生成・地形・コア・当たり判定・テクスチャ
    entities/          プレイヤー・敵・タワー・弾丸とそのモデル生成
    fx/                粒子・トレーサー・爆発・HP バー・画面演出・レーダー
  ui/                  React 製の HUD / メニュー / 建設パネル / リザルト
```
