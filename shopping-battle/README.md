# 列に並べ！ショッピングバトル

スーパー「ならぶ屋」の大特売で、10本のレジ列に並んで商品を取り合い、集めた力で4人乱戦バトルをするスマホ向けブラウザゲームです。
ビルド不要の HTML 1枚 (`index.html`) で動きます。

## 遊び方

### ① 買い物フェーズ（2分）
- 店には10本のレジ列があります。横にスクロールして見て回り、「ここに並ぶ」で最後尾に並びます。上のミニマップをタップするとその列まで移動します。
- 先頭まで進むと、その列の商品が手に入ります。
- 一般のお客さんも商品を買っていきます。在庫が0になると、その列の商品は別のものにランダムで入れ替わります。
- ライバル3人(CPU)も同じ商品を狙っています。
- ときどきタイムセールがあり、その列のレジが速くなって★レア商品(効果2倍)が並びます。

| 種類 | 内容 |
|---|---|
| スキル | バトルで使う技。同じものを重ねるとレベルアップ。バトルには3つまで持っていける |
| パッシブ | 吸血・反射・会心・回避・根性など。全部効く |
| 基礎強化 | 体力・攻撃・防御・速さ・攻撃速度 |
| 並びスキル | 割り込み／バナナの皮／井戸端会議／セルフレジ／入荷ベル／買い占め |
| 福袋 | ランダムな商品が3個（★は5個） |

### 買い物の特別イベント
- **ガチャガチャ**：いつでも並べる列。普通の商品・★レア・福袋、まれに★★伝説アイテムが出ます。
- **伝説のレジ**：買い物中に2回だけ現れる金色の列。★★伝説アイテムが1個だけ並びます。一般客は買いません。
- **投げ売りタイム**：残り20秒で全レジが2倍速になり、商品が全部★レアになります。
- **日替わりチラシ**：日によって売り場に多く出る商品や特別ルールが変わります。

### ★★伝説アイテム
| アイテム | 効果 |
|---|---|
| 🏎️ 黄金のカート | 会場を突き抜ける超ダッシュ。通り道の全員に特大ダメージ |
| 🌪️ バーゲンの嵐 | ほかの全員の今の体力を25%けずって気絶させる |
| 🖤 ブラックカード | スキルCT-35%・スキルダメージ+25% |
| 👑 永久VIP会員証 | 最大体力+60・毎秒1.5%回復・根性+1 |

### ② バトルフェーズ（乱戦）
- 左側をドラッグして移動、👊で通常攻撃、右のボタンでスキルを使います。
- 会場は広く、画面は自分を追いかけます。画面の外にいる相手は矢印で表示されます。
- 会場は4種類あり、ステージごとに仕掛けがあります。どの会場にも、拾うと回復・攻撃アップなどの効果があるアイテムが落ちています。
  - スーパー：アイテムがよく落ちる
  - 百貨店：エスカレーターに乗ると流される
  - 商店街：無人カートが暴走して横切る
  - 深夜のコンビニ：暗くて遠くが見えず、棚が倒れてくる
- 35秒たつと閉店シャッターが下り始め、外側にいるとダメージを受けます。
- 最後まで残った人が優勝です。
- ⏸ボタン（PC は P／Esc）で一時停止して、自分とライバルのスキル・パッシブの効果を確認できます。

### 効果の確認
- キャラ選択・商品の詳細・持ち物・バトル準備・一時停止・結果のどの画面でも、アイテムをタップすると効果の数値と次のレベルの効果が見られます。
- バトル準備のスキル選びには、それぞれのダメージとクールタイムが表示されます。
- 買い物中の並びスキルは、長押しか「？」ボタンで説明が見られます。
- PC では WASD／矢印キーで移動、J／スペースで攻撃、K・L・;（または 1・2・3）でスキルを使います。

## 隠しキャラ
解放の記録は、遊んだブラウザに保存されます。
| キャラ | 特徴 | 解放条件 |
|---|---|---|
| 🧑‍💼 店長 | 開店時に商品3つを入手（その商品は売り場に出ない）。自分の列が速い。攻撃・防御が高く遅い。スキル2枚＋固有「閉店」 | 10%で5人目として乱入する「本気の店長」を差し置いて1位 |
| 🕴️ テンバイ（転売ヤー） | いつも2個買う。ただし列の移動が遅く、一般客に割り込まれやすい。体力低め | 累計3回1位 |
| 👸 マダム（大富豪） | 「お釣りはいらないわ」で前の2人を買収（15秒ごと）。執事セバスが別の列に並び、バトルでも一緒に戦う | 累計5回1位 |
| 🕵️ Gメン（万引きGメン） | 割り込み・バナナを使ったライバルを確保して最後尾へ。バナナと井戸端会議が効かない。固有スキル「確保」「変装」 | タイトル画面の隠しボタン |

解放したキャラは、CPUのライバルとしても登場します。本気の店長は、各並びスキルを1つずつ持ち、攻撃・防御・体力も強化されています。
