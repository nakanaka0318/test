# 列に並べ！ショッピングバトル

スーパー「ならぶ屋」の大特売で、10本のレジ列に並んで商品を取り合い、集めた力で4人乱戦バトルをするスマホ向けブラウザゲームです。
ビルド不要の HTML 1枚 (`index.html`) で動きます。

## 遊び方

### ① 買い物フェーズ（2分）
- 店には10本のレジ列があります。横にスクロールして見て回り、「ここに並ぶ」で最後尾に並びます。上のミニマップをタップするとその列まで移動します。
- 先頭まで進むと、その列の商品が手に入ります。
- 一般のお客さんも商品を買っていきます。在庫が0になると、その列の商品は別のものにランダムで入れ替わります。
- ライバル3人(CPU)も同じ商品を狙っています。
- ときどきタイムセールがあり、その列のレジが速くなって★レア商品(効果2倍)が並びます。

| 種類 | 内容 |
|---|---|
| スキル | バトルで使う技。同じものを重ねるとレベルアップ。バトルには3つまで持っていける |
| パッシブ | 吸血・反射・会心・回避・根性など。全部効く |
| 基礎強化 | 体力・攻撃・防御・速さ・攻撃速度 |
| 並びスキル | 割り込み／バナナの皮／井戸端会議／セルフレジ／入荷ベル／買い占め |
| 福袋 | ランダムな商品が3個（★は5個） |

### ② バトルフェーズ（4人乱戦）
- 左側をドラッグして移動、👊で通常攻撃、右のボタンでスキルを使います。
- 35秒たつと閉店シャッターが下り始め、外側にいるとダメージを受けます。
- 最後まで残った人が優勝です。
- PC では WASD／矢印キーで移動、J／スペースで攻撃、K・L・;（または 1・2・3）でスキルを使います。
